Manual software lookup

Assess specific software you name (vendor, product, version) against NVD vulnerability data using the same matching engine. Nothing is inspected on any machine - the result is only as accurate as what you enter.

The exact version matters: with no version, the affected-version ranges cannot be evaluated and any CVEs shown are marked indeterminate. Unrecognised vendor/product names are matched by name only and marked potential.
